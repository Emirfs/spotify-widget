# CONTEXT

Windows Electron widget showing current Spotify playback without Spotify API credentials.

## Map

| Path | Purpose |
|---|---|
| `main.js` | Electron main process |
| `renderer.js` | Widget UI behavior |
| `spotify-monitor.ps1` | Windows playback monitor |
| `style.css` | Widget styling |
| `package.json` | Scripts and packaging configuration |
